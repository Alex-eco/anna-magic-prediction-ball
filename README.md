# Magic Prediction Ball

A small desktop-first interactive Anna App inspired by the classic prediction ball.

## How it works

Ask a question, then click or press Enter/Space on the ball. The ball animates and returns a random playful answer.

## Anna integration

The app is intentionally self-contained:

- no backend
- no API calls
- no Executa
- no LLM
- no external origins
- no host tools or permissions
- desktop-first UI

All answers are randomly selected locally in the browser/app view. They are for entertainment only and should not be treated as factual predictions or advice.

## Run locally

Open `index.html` in a modern desktop browser.
